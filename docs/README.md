## Module map

| Module | File | Role |
|------|------|------|
| **DataTransformer** | `core.py` | in-memory chainable API, `DictWrapper` / `ListWrapper` attribute access |
| **Expressions** | `expr.py` | one engine behind every `--where` / `select` / `map` / `sort` / `group` / `join` string (row is `x`) |
| **Primitives** | `ops.py` | filter / select / map / explode / sort / shuffle / group / join / clean / transform / dedupe / split / schema inference, shared by CLI and pipelines |
| **Streaming** | `streaming.py` | `StreamingTransformer`, `open_stream`, sharded IO, constant memory |
| **Pipeline** | `pipeline.py` | YAML runner; step types are CLI command names |
| **Presets / schema / tokens / converters / frameworks** | `presets.py`, `schema.py`, `tokenizers.py`, `converters.py`, `framework.py` | training-format specifics |
| **Lineage** | `lineage.py` | sidecar files, `dt history` |
| **CLI** | `__main__.py`, `cli/` | typer commands; `cli/pipe.py` is the stdin/stdout layer; `cli/view/` is the browser |
| **IO** | `storage/io.py` | JSONL/JSON (+`.gz`), CSV/TSV, Parquet, Arrow, Excel, FlaxKV via Polars/orjson |
| **Field paths** | `utils/field_path.py` | `a.b`, `a[0].b`, `a.#`, `a[*].b` |
