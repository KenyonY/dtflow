## 回复起点

- “和 jq 有什么区别？”：jq 很适合 JSON 加工；dtflow 把对话/偏好/指令当作样本浏览，
  并提供训练格式转换与框架导出。按你需要的步骤选工具，可以放进同一条管道。
- “能直接开始训练吗？”：生成数据和配置模板；标准文本映射已经验证。
  训练参数还要按你的模型、数据和硬件调整；演示没跑 GPU 训练。
- “数据发到服务器了吗？”：这组统计、筛选、转换、校验和导出命令处理本地文件，
  不调用 LLM。安装会下载依赖；需要模型 tokenizer 的其它命令另看对应帮助。
- “为什么 dry-run 退出码不是 0？”：10 表示预演完成，0 表示实际执行成功。
  `run` 只验证步骤，不能代替小样本实际运行。
- “报错了”：请提供版本、完整命令、退出码、stderr，以及可公开的最小脱敏样本；
  先复现和定位，再承诺修复。不索取原始敏感数据。
